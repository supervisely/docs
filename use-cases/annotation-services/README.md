# Annotation Services

Supervisely Annotation Service runs annotation projects for clients end to end: a calibration batch, finalized guidelines, a dedicated team, project-specific automation, multi-level QA, and delivery of an approved dataset. The use cases in this section show how such projects are run.

* [Instance Segmentation Annotation Service](instance-segmentation-annotation-service.md): calibrate on 20 images, add project-specific automation, and deliver 5,000 TACO images with approximately 300,000 instance masks.
